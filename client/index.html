Real-Time Collaborative Web IDE & Whiteboard

Collabo is a high-performance in-browser collaborative coding environment with live multi-cursor synchronization powered by Yjs CRDTs, Monaco Code Editor, multi-file workspaces, in-browser code execution for Python, JavaScript, and TypeScript, collaborative whiteboard canvas, and Gemini AI assistant.
